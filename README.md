# Fitness Tracker

A Java-based fitness tracking application that helps users monitor their BMI, get personalized diet and exercise plans.

## Features

- User authentication system
- BMI calculation and tracking
- Personalized diet recommendations
- Custom exercise plans
- Visual BMI trend analysis
- MySQL database integration

## Technologies Used

- Java
- Swing (for GUI)
- MySQL
- JFreeChart (for graphs)

## Setup

1. Install Java Development Kit (JDK)
2. Set up MySQL database
3. Import required libraries:
   - MySQL Connector
   - JFreeChart

## Database Configuration

Create a MySQL database named `fitness_tracker` and update the credentials in `DatabaseConnection.java` if needed.
